# ImageJ 图片编辑工具功能性设计文档

## 1. 项目概述

ImageJ 是一个基于 Qt 框架的跨平台图片编辑工具，采用 C++17 标准开发。工具旨在提供简单易用的图像编辑功能，同时保持代码质量和可维护性。项目将严格遵守 Google C++ 编码规范，并采用增量开发模式，每次只实现一个功能。

## 2. 目标用户

- 普通用户：需要快速进行简单的图片编辑操作
- 开发者：学习 Qt 和 C++ 图像处理技术的参考项目
- 教育用途：作为图像处理算法的教学示例

## 3. 功能需求

### 3.1 核心功能（按优先级排序）

#### 第一阶段：基础功能
1. **图像文件操作**
   - 支持打开常见图像格式（PNG、JPEG、BMP）
   - 支持保存图像到文件
   - 支持另存为不同格式

2. **基本图像查看**
   - 图像显示（适应窗口、原始大小）
   - 缩放（放大、缩小、适应窗口）
   - 平移（拖拽查看大图像）

#### 第二阶段：编辑功能
3. **几何变换**
   - 旋转（90°、180°、270°、任意角度）
   - 翻转（水平、垂直）
   - 裁剪（矩形选择裁剪）
   - 调整大小（按像素或百分比）

4. **颜色调整**
   - 亮度、对比度调整
   - 色相、饱和度调整
   - 灰度化
   - 反色
   - 阈值化（二值化）

5. **滤镜效果**
   - 模糊（高斯模糊、均值模糊）
   - 锐化
   - 边缘检测（Sobel、Canny）
   - 浮雕效果

#### 第三阶段：高级功能
6. **选择工具**
   - 矩形选择
   - 椭圆选择
   - 自由选区（套索工具）
   - 魔术棒（基于颜色选择）

7. **绘图工具**
   - 画笔（不同大小、颜色）
   - 橡皮擦
   - 形状工具（直线、矩形、椭圆）
   - 文字工具

8. **图层支持**（可选）
   - 基本图层管理
   - 图层混合模式

### 3.2 用户界面功能
- 主菜单：文件、编辑、视图、工具、帮助
- 工具栏：常用工具快速访问
- 右侧面板：工具选项、图层管理、历史记录
- 状态栏：图像信息、操作提示
- 快捷键支持

## 4. 非功能需求

### 4.1 性能要求
- 打开图像文件时间：< 2秒（10MP图像）
- 基本操作响应时间：< 100ms
- 内存使用：高效管理大图像内存

### 4.2 兼容性要求
- 操作系统：Windows、Linux、macOS
- 图像格式：PNG、JPEG、BMP（通过Qt支持）
- 屏幕分辨率：支持高DPI显示

### 4.3 质量要求
- 代码质量：遵循 Google C++ 编码规范
- 可维护性：模块化设计，易于扩展
- 用户体验：直观的界面，清晰的反馈

## 6. 模块设计

### 6.1 核心模块

1. **ImageDocument 模块**
   - 职责：管理图像数据，提供图像加载/保存功能
   - 类设计：
     ```cpp
     class ImageDocument {
     public:
         bool LoadFromFile(const std::string& path);
         bool SaveToFile(const std::string& path);
         QImage& GetImage();
         const QImage& GetImage() const;
         // 图像信息：尺寸、格式、深度等
     private:
         QImage image_;
         std::string file_path_;
     };
     ```

2. **ImageCanvas 模块**
   - 职责：显示图像，处理用户交互（缩放、平移）
   - 类设计：
     ```cpp
     class ImageCanvas : public QWidget {
         Q_OBJECT
     public:
         explicit ImageCanvas(QWidget* parent = nullptr);
         void SetImage(const QImage& image);
         // 视图控制：缩放、平移、适应窗口
     protected:
         void paintEvent(QPaintEvent* event) override;
         void mousePressEvent(QMouseEvent* event) override;
         void mouseMoveEvent(QMouseEvent* event) override;
         void wheelEvent(QWheelEvent* event) override;
     };
     ```

3. **EditOperation 模块**
   - 职责：封装图像编辑操作，支持撤销/重做
   - 类设计：
     ```cpp
     class EditOperation {
     public:
         virtual ~EditOperation() = default;
         virtual void Apply(QImage& image) = 0;
         virtual void Undo(QImage& image) = 0;
         virtual QString GetDescription() const = 0;
     };

     class RotateOperation : public EditOperation { /* ... */ };
     class CropOperation : public EditOperation { /* ... */ };
     // 其他操作类...
     ```

4. **OperationHistory 模块**
   - 职责：管理操作历史，实现撤销/重做功能
   - 类设计：
     ```cpp
     class OperationHistory {
     public:
         void Push(std::unique_ptr<EditOperation> operation);
         bool CanUndo() const;
         bool CanRedo() const;
         void Undo(QImage& image);
         void Redo(QImage& image);
         void Clear();
     private:
         std::vector<std::unique_ptr<EditOperation>> history_;
         size_t current_index_ = 0;
     };
     ```

5. **ToolManager 模块**
   - 职责：管理各种编辑工具（选择、绘图等）
   - 类设计：
     ```cpp
     class Tool {
     public:
         virtual ~Tool() = default;
         virtual void OnMousePress(const QPoint& pos) = 0;
         virtual void OnMouseMove(const QPoint& pos) = 0;
         virtual void OnMouseRelease(const QPoint& pos) = 0;
         virtual void DrawOverlay(QPainter& painter) = 0;
     };

     class ToolManager {
     public:
         void SetActiveTool(ToolType type);
         Tool* GetActiveTool() const;
     };
     ```

## 9. 开发计划

### 9.1 开发原则
- **增量开发**：每次只实现一个功能
- **测试驱动**：每个功能都有对应的测试
- **代码审查**：遵循编码规范，定期审查

### 9.2 开发阶段

#### 阶段 1：基础框架（2-3周）
1. 完善现有 Qt 框架：主窗口、画布、侧边栏
2. 实现图像加载和显示功能
3. 实现基本的视图控制（缩放、平移）

#### 阶段 2：基础编辑功能（3-4周）
4. 实现旋转、翻转操作
5. 实现裁剪功能
6. 实现调整大小功能
7. 实现撤销/重做系统

#### 阶段 3：颜色调整（2-3周）
8. 实现亮度、对比度调整
9. 实现灰度化、反色
10. 实现阈值化

#### 阶段 4：滤镜效果（2-3周）
11. 实现模糊滤镜
12. 实现锐化滤镜
13. 实现边缘检测

#### 阶段 5：选择与绘图工具（3-4周）
14. 实现选择工具
15. 实现绘图工具
16. 实现文字工具

#### 阶段 6：高级功能（可选）
17. 图层支持
18. 更多滤镜和效果
19. 批量处理功能

## 10. 风险与缓解

### 10.1 技术风险
- **大图像内存占用**：使用分块处理或流式处理
- **复杂算法性能**：使用多线程或GPU加速
- **跨平台兼容性**：定期在多个平台测试

### 10.2 项目管理风险
- **功能蔓延**：严格遵守"每次只实现一个功能"原则
- **代码质量下降**：坚持代码审查和规范检查
- **进度延迟**：每个功能设定明确的时间box

## 11. 验收标准

每个功能完成后必须满足：
1. 功能正确实现，无重大bug
2. 代码符合 Google C++ 编码规范
3. 有相应的单元测试
4. 用户界面友好，操作流畅
5. 性能满足非功能需求
