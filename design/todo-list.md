# ImageJ 开发任务清单

## 版本信息
- **项目名称**: ImageJ 图片编辑工具
- **编程语言**: C++17
- **GUI框架**: Qt 6
- **编码规范**: Google C++ Style Guide
- **开发原则**: 每次只实现一个功能，确保质量后再进行下一个
- **测试原则**: 每个功能都必须要有单元测试

## 任务状态说明
- **未开始**: 任务尚未开始
- **进行中**: 任务正在开发中
- **已完成**: 任务已完成并通过测试
- **阻塞**: 任务因依赖关系被阻塞
