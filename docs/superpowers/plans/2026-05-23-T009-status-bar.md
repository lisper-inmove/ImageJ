# T009: Status Bar Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add QStatusBar to MainFrame with default "就绪" message, permanent "图像信息" label, and temporary message support.

**Architecture:** QStatusBar is added to MainFrame's QVBoxLayout below the splitter. It uses `showMessage()` for default/temporary messages and `addPermanentWidget()` for the right-side image info label. All managed via Qt parent-child ownership.

**Tech Stack:** C++17, Qt 6 Widgets, GTest + QTest

```cpp
TEST_F(StatusBarTest, HasPermanentImageInfoLabel) {
  MainFrame frame;
  frame.show();
  QTest::qWait(50);

  QStatusBar* status_bar = frame.findChild<QStatusBar*>();
  ASSERT_NE(status_bar, nullptr);

  // Find permanent QLabel with "图像信息" text
  bool found = false;
  for (QWidget* widget : status_bar->findChildren<QLabel*>()) {
    if (widget->parent() == status_bar &&
        qobject_cast<QLabel*>(widget)->text() == "图像信息") {
      found = true;
      break;
    }
  }
  EXPECT_TRUE(found);
}

TEST_F(StatusBarTest, ShowTemporaryMessage) {
  MainFrame frame;
  frame.show();
  QTest::qWait(50);

  QStatusBar* status_bar = frame.findChild<QStatusBar*>();
  ASSERT_NE(status_bar, nullptr);

  status_bar->showMessage("测试消息", 5000);
  QTest::qWait(50);

  EXPECT_EQ(status_bar->currentMessage().toStdString(), "测试消息");

  // Clear message
  status_bar->clearMessage();
  QTest::qWait(50);

  EXPECT_EQ(status_bar->currentMessage().toStdString(), "就绪");
}
```

```cpp
void MainFrame::setupStatusBar() {
  status_bar_ = new QStatusBar(this);
  status_bar_->setSizeGripEnabled(true);

  // Default message on the left
  status_bar_->showMessage("就绪");

  // Permanent image info label on the right
  QLabel *image_info_label = new QLabel("图像信息", status_bar_);
  status_bar_->addPermanentWidget(image_info_label);
}
```
